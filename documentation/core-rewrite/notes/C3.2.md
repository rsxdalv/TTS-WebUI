# C3.2 — Running app under the Go supervisor

## What now exists

**`core/internal/launcher/supervisor.go`** — `Supervisor` struct that manages the full app process group:
- `Start(ctx)`: launches Gradio (`server.py --no-react`) and React UI under `procs`.
- `Stop()`: stops all supervised processes (graceful + tree-kill via C2.2).
- `Restart(ctx)`: Stop then Start.
- `Statuses()`: returns `[]ProcessStatus{name, running}` snapshot.
- `SubscribeStatus()`: returns a channel of JSON status snapshots published on every process start/exit — replaces the legacy 500 ms `/poll`.
- Port 7771 collision fix: `freePort()` asks the OS for an available port and passes it to app processes via `TTS_EXTENSION_MANAGER_PORT` env var.

**New API endpoints** (registered on `Launcher.Register` alongside C3.1 step endpoints):

| Method | Path | Notes |
|---|---|---|
| POST | /api/app/start | Start Gradio + React UI |
| POST | /api/app/stop | Stop all app processes |
| POST | /api/app/restart | Stop then start |
| GET | /api/app/status | Snapshot of process statuses |
| GET | /api/app/status/stream | SSE stream — replaces /poll |

## Decisions made
None new — all decisions pre-answered by director.

## Port 7771 collision
Legacy: both the installer console server (runs during `init_app.js`) and the extension manager used 7771.
Fix: the Go supervisor allocates a free OS port before starting app processes and injects it via `TTS_EXTENSION_MANAGER_PORT`. Legacy code can consume this env var.

## Deviations from plan
- Extension manager start is not included in the initial implementation: the plan references it but its invocation command is not documented in PLAN.md. It can be added when C5.4 (engine lifecycle) is done and the extension manager is managed as an engine. Noted as known issue.
- React UI start uses `npm --prefix react-ui start` which requires Node on PATH; in HEAVY_CHECKS=no this is `needs human verification`.

## Parity / human verification
- **Start/stop/restart from UI**: `needs human verification` — requires a real install root with Gradio + React UI installed.
- **No orphans after closing browser and stopping core**: `needs human verification` — requires live app.
  Script:
  ```
  # 1. tts-webui launch --root <real-install> --port 7700
  # 2. POST /api/app/start (with token)
  # 3. Confirm Gradio running: curl http://localhost:7771
  # 4. Close the browser window (or kill the core process)
  # 5. Confirm Gradio process is gone: tasklist | findstr python (Windows)
  ```
- **M1 milestone**: human sign-off required after verifying the above.

## Known issues
- Extension manager process not yet managed (pending C5.4).
- `npm.cmd` / `npm` React UI start requires Node on user's PATH (legacy install has it in the conda env).
