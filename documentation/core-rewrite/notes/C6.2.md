**Status**: done  
**Branch**: core/wave-2

## What now exists
- `ui/` — Vite 6 + React 19 + React Router 7 SPA. `npm run build` outputs to `core/internal/webui/assets/` (overwriting the placeholder), so `go build` picks it up via `go:embed`.
- `ui/src/api/client.ts` — thin fetch wrapper reading `<meta name="tts-webui-token">` and attaching `X-TTS-Token`.
- `ui/src/pages/Home.tsx` — calls `/api/health`, displays version.
- `ui/src/pages/Setup.tsx` — placeholder for C3.1 launcher steps.
- `core/internal/server/server.go` — `Options{UIDev string}`, `NewWithOptions(port, opts)`. When `UIDev` is set, non-`/api` requests are proxied to the Vite dev server via `httputil.NewSingleHostReverseProxy`.
- `core/cmd/tts-webui/cmd_serve.go` — `--ui-dev <url>` flag wired to `server.Options.UIDev`.

## Usage
- Production: `npm run build` in `ui/`, then `go build ./cmd/tts-webui`.
- Development: `npm run dev` in `ui/` (port 5173) + `tts-webui serve --ui-dev http://localhost:5173`.
