## API endpoints registered
```
GET  /api/engines                 → JSON list + status for all registered engines
POST /api/engines/{id}/start      → start engine; returns EngineStatus JSON
POST /api/engines/{id}/stop       → stop engine; 204 No Content
GET  /api/engines/{id}/logs       → SSE stream of engine stdout/stderr
```
