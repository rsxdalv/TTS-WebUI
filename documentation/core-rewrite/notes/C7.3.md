# C7.3 — App distribution via uv package

## What now exists

**`core/internal/app/`** — new package:
- `CurrentVersion(root)` — reads `installer_scripts/.app_version`; returns `""` on first install
- `IsMigratingFromGit(root)` — true if `.git_version` exists but `.app_version` does not
- `LatestVersion(ctx)` — `GET https://pypi.org/pypi/tts-webui/json`, parses `.info.version`
- `Update(ctx, root)` — ensures uv, fetches latest version, runs `uv pip install --python <venvPath> tts-webui==<version>`, writes `.app_version` atomically

**`core/cmd/tts-webui/cmd_app.go`** — subcommands:
- `tts-webui app update [--root <dir>] [--check-only]`
- `tts-webui app version [--root <dir>]`

## Decisions
D-open-3 confirmed: pinned `tts-webui` package installed by uv into main venv. Recorded in DECISIONS.md.

## Migration path for existing git installs
```bash
# Existing installs have installer_scripts/.git_version
# After first `tts-webui app update`: .app_version is written, git pull is no longer needed
# .app_version first line: "migrated from git install", second line: version string
# tts_webui/ source tree is superseded by the installed package
# Rollback: reinstall from git (git clone + init_app.js)
```

## Tests
10 unit tests pass (`go test ./internal/app/...`). Integration test (real PyPI) behind `-tags integration`
tag; actual `uv pip install` test needs human verification on a live install.

## Parity
Replaces `init_app.js` `git pull` path. PyPI version is the new source of truth for app releases.
The `.git_version` marker is left untouched; `.app_version` is the new marker for uv mode.

## Known issues / deviations
- The `--check-only` flag exits with code 1 (via error return) to signal "update available". This is
  consistent with `update --check-only` semantics but may be surprising; document in CLI help if needed.
- `tools.EnsureAll` is called on every `Update` invocation. This is safe (it's a no-op when tools exist)
  but adds a small stat overhead.

## What C9.1 needs to know
The start scripts should call `tts-webui app update` once at launch (after env create) to ensure the
package is installed. The `--check-only` flag can gate a user-visible "update available" prompt.
