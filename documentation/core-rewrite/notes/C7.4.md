## Catalog format
```json
{
  "schema": 1,
  "engines": [ { "package_name": "...", "name": "...", "engine": {...} } ]
}
```
- `schema == 0` (absent): treated as valid legacy format (extensions.json compat).
- `schema != 0 && schema != 1`: returns `ErrUnknownSchema` + cached copy.
- Network failure + cache present: returns cached copy, logs warning, nil error.
- Network failure + no cache: returns error.
