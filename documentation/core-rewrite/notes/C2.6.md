# C2.6 — Browser auth for SSE, media and downloads

**Status**: built  
**Branch**: core/r2-wave-1  
**Commit**: 78c4320

## What now exists

- `core/internal/server/server.go`:
  - `serveIndexWithToken` now sets `Set-Cookie: tts-token=<token>; SameSite=Strict; HttpOnly; Path=/`
    on every response that serves `index.html`.
  - `tokenGuard` accepts a request if EITHER `X-TTS-Token` header matches OR `tts-token` cookie matches.
  - Existing Host and Origin guards are unchanged.
- `core/internal/server/server_test.go`: added
  - `TestCookieAuth` — request with valid cookie, no header → passes guard
  - `TestNoCookieNoHeader` — no auth → 403
  - `TestCookieAuthForeignOrigin` — valid cookie + foreign Origin → 403 (Origin guard fires first)
  - `TestIndexSetsCookie` — GET / response sets the `tts-token` cookie

## Decisions
None. Implementation follows the gap spec exactly.
