## Caveat

The current `manifest.Load` only reads `tabsInGroups.extensions` (the extension-management section), 
NOT `tabsInGroups.text-to-speech` where these 5 entries live. The flags in extensions.json are correct 
and ready; the manifest loader needs a one-line fix to iterate all `tabsInGroups.*` groups — this is 
part of C5.5's scope.
