# Compare case files

Each file is a JSON array of `compare.Case`, run with
`compare -next <Next URL> -go <gosrv URL> <file>` (see CONTRACTS.md section 8).

- `gradio-file-proxy.json`: needs a Gradio stub on the port set in `GRADIO_BACKEND` for both Next and gosrv.
- `webui-generations.json`: needs these fixtures in the install root next to `react-ui`:
  `outputs/a.wav` (31 bytes), `outputs/sub/b c.txt`, `outputs/.hidden`, `outputs/.hiddendir/x.txt`,
  `outputs/emptydir/`, `outputs/ünï.html`, `outputs/UPPER.PNG`, `collections/c.json`, `voices/x.npz` (3,000,000 bytes),
  `outputs-rvc/s.js`, `voices-tortoise/README`, `favorites/f.ogg`, `config.json`, `secretdir/s.txt`.
  Conditional-request cases (If-None-Match with the real ETag) were run separately with the validators read from Next.
- `upload.json`: generated by `node gen-upload.js upload.json`; needs `react-ui/public/file-input-cache/` in the install root of both servers. Written files must be compared separately (snapshot the directory after a Next run and after a Go run); the harness compares responses only.
- `data-outputs.json`: fixtures from `gen-fixtures-outputs.js` (edit its root path); the BUILD_ID inside nextPath must be replaced with `react-ui/.next/BUILD_ID`; use collection names that were not prerendered at build. Next side is `/_next/data/<BUILD_ID>/outputs/<name>.json`, compared on `pageProps.outputs` only.
- `data-bark-voices.json`: fixtures from `gen-fixtures-bark-voices.py` (needs numpy; edit its target folder). The page is prerendered, so build react-ui with the fixtures in place and compare against that build; replace the BUILD_ID in nextPath.
