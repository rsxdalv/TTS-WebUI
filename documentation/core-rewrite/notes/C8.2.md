## Cancel design

Mode `"disconnect"`: lifecycle.Manager.Cancel calls the registered `cancelFn`, closing the upstream request context. The llama.cpp HTTP server does NOT natively abort inference on disconnect; generation continues to completion.

Recommended fallback: **sentence-chunked requests** — caller sends one sentence at a time and stops sending when cancelled. This limits wasted GPU time to one sentence.

Last resort: `lifecycle.Manager.Stop` + `Start` (kill and restart). Acceptable since audio.cpp queues at depth 1; the process is idle between requests.
